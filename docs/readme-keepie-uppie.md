# Keepie-Uppie — readme executivo

**O que é:** embaixadinha infinita e vertical — a bola cai, o jogador toca pra lançá-la pro alto; altura em metros é o placar; obstáculos desviam a bola e powerups/consumíveis variam a run.
**Título de trabalho:** *Keepie-Uppie* (EN) / *Embaixadinha* (BR) — nome TBD.
**Feel:** "um sidescroller infinito, mas para cima".
**Status:** MVP01 implementado (F0–F7) e em ciclo de ajustes. Build atual: **`0.3.0-mvp1`** — queda mais lenta e toque de 75 u (`fix4`), céu claro + paralaxe (`fix5`), nuvens + Aimed Shot estilingue (`fix6`), força pela queda desde o ápice (`fix7`), bola mais alta + metade de baixo 30%+ (`fix8`), fundo com ganho crescente (`fix9`), dificuldade por ritmo: queda +75 u/s a cada 500 m, até 1200 (`docs/release/fix10-queda-progressiva.md`) e, agora, a bola de futebol + damping lateral + loja de consumíveis (`docs/release/fix11-bola-damping-e-loja.md`). Próximo: testar a loja no celular; depois o playtest das 6 perguntas (`docs/playtest-mvp01.md`).
**Documento principal:** `ideia-semente.md`
**Como retomar:** ler `gdd-keepie-uppie.md` (regras consolidadas) e `plano-implementacao-mvp01.md` (handoff pro orquestrador). Histórico completo: `ideia-semente.md` (decisões rounds 1-6). MVP1: core kick (ângulo por ponto de toque oposto, força pela queda desde o ápice com piso curto, whiff neutro), catraca + linha de morte, paredes, obstáculos (birds/hard/soft/breakable), argolas/molas/moedas, Aimed Shot (2s, timeout com força média default, armado sem prazo) e Magnet (15s reset), perfect + streak. FORA: time-warp, chutão, multiball, zero-G, saves/AD, loja, biomas. PRÓXIMO: orquestrador implementa MVP1 → playtest responde as 6 perguntas do plano → aí pós-MVP.

**Regra mais importante já definida:** só se chuta a bola pro alto se ela estiver caindo (anti-spam, gera ritmo).
